Welcome! This is a set of guides to introduce you to Python, a popular starter programming language.

You do not need any coding experience to get started! By the end, you'll (hopefully) have the knowledge needed to make your very own app!

This is split into a few different guides. Start [here](https://github.com/bunnybunnybun/Python-GTK4-Tutorial/blob/main/Getting%20started%20with%20Python.md) to learn the basics of Python and Git. If you have already learned the basics of Python and Git, you can skip ahead to the second guide.

After you have done that, you can move on to [this](https://github.com/bunnybunnybun/Python-GTK4-Tutorial/blob/main/Making%20an%20app.md) guide to learn how to create an actual app!

This series of guides is not yet done, and will be updated over time. But for now, enjoy!
